Памятка по настройке Raspberry Pi
  1. Запишите на microSD образ Raspberry Pi OS Lite (64-bit) через Raspberry Pi Imager. При записи в настройках включите SSH и укажите Wi-Fi.
  2. Вставьте microSD в плату, включите питание и подключитесь по SSH: ssh <user>@<host>.
  3. Вставьте и выполните полученную команду установки.
  4. Скрипт установит пакеты, склонирует код, создаст службу growvision-edge и команду gv-update.
  5. Для последующих обновлений на плате запускайте gv-update. Для смены Wi-Fi используйте sudo nmtui.
