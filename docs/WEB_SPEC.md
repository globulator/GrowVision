# GrowVision — Спецификация веб-приложения (Web SPA)

Документ описывает веб-клиент GrowVision (`clients/web/`), пересобранный с нуля как лёгкий, эстетичный и безотказный плеер таймлапсов, просмотрщик тестовых снимков и будущий помощник первичного подключения Raspberry Pi.

Опирается на `API_CONTRACT.md`, `DB_SCHEMA.md`, `BOT_SPEC.md` и `REPO_AND_VERSIONING.md`.

---

## 1. Назначение и жёсткие ограничения

- **Статус документа:** защищённый архитектурный документ (меняется только с согласия пользователя, `REPO_AND_VERSIONING.md`, раздел 5.3).
- **Стек:** чистые HTML5, CSS3 и JavaScript (нативные ES-модули `<script type="module">`). Node.js, сборщики, фреймворки (React/Vue и т. п.), внешние CDN и веб-шрифты **запрещены**: приложение должно полностью работать в локальной сети без доступа к интернету.
- **Жёсткий запрет на эмодзи:** в коде `clients/web/` (HTML, CSS, JS, текстах кнопок, заглушек и сообщений) **полностью запрещены любые Unicode-эмодзи**. Используются **исключительно аккуратные inline SVG-иконки**. Там, где смысл иконки интуитивно понятен (навигация, закрытие, обновление, скачивание, вход/выход, показ пароля), отображается только иконка без текста (с `title` и `aria-label`).
- **Никаких системных окон браузера:** `window.alert`, `window.confirm`, `window.prompt` полностью запрещены.
- **Визуальный стиль:** современная тёмная стеклянная тема, мягкий размытый фон с растениями (локальный ассет без CDN), плавные анимации загрузки и стильные SVG-заглушки. Адаптивная вёрстка от `360 px` (телефоны) до широких мониторов; тач-цели кнопок не менее `44×44 px`.
- **Раздача и безопасность:** статика раздаётся FastAPI через `StaticFiles` на `/` по относительным путям (`/api/...`, `/media/...`). `X-Client-Key` в браузере не используется; авторизация работает через `HttpOnly`-cookie (`SameSite=Lax`). Все пользовательские данные рендерятся безопасно через `textContent` (защита от XSS).

## 2. Структура экрана (шапка, панель раздела, карточки, подвал)

### 2.1. Верхняя шапка (Header)
- **Слева:** SVG-логотип и название `GrowVision`.
- **Справа:**
  - **Индикатор роли (всегда отображается):** аккуратный бейдж текущей роли — **`Гость`**, **`Биолог`** или **`Разработчик`** (с визуальным отличием по цвету акцента). Для авторизованных пользователей рядом с бейджем роли компактно выводится имя.
  - **Гость:** кнопка «Войти» (только SVG-иконка с `title`/`aria-label`).
  - **Авторизованный пользователь (`biologist` / `developer`):** зарезервированный слот под кнопку «Подключить RPi» (для `developer`, будет активирован на следующем этапе) и кнопка «Выйти» (SVG-иконка).

### 2.2. Панель инструментов раздела (Sub-toolbar)
Располагается сразу под шапкой над сеткой карточек, выполнена в едином стиле с интерфейсом и содержит инструменты текущего раздела (для Гостя — только раздел «Установки»):
- Заголовок раздела («Установки»).
- Кнопка обновления списка установок (SVG-иконка с анимацией вращения во время запроса; обновление сбрасывает кеш превью, чтобы подтягивались свежие кадры).

### 2.3. Сетка карточек установок
- Отображаются **только активные** установки (архивные в вебе не показываются).
- Если активных установок `0` — в рабочей области отображается аккуратная стилизованная SVG-заглушка пустого состояния.
- **Для Гостя на карточке:**
  - Превью последнего планового кадра (при `onerror` подставляется SVG-заглушка, а не битая картинка браузера).
  - Название установки и культура.
  - Если у установки `0` кадров: вместо фото выводится живая, аккуратная анимированная SVG-заглушка (стилизованный значок растения/камеры в ожидании, минимум текста).
  - Кнопки действий у Гостя отсутствуют.
- **Для авторизованного пользователя (любая роль — `biologist` или `developer`) на карточке появляются две кнопки:**
  - **«Галерея»** (SVG + подпись) — **неактивна (`disabled`), если у установки `0` кадров**.
  - **«Тестовый снимок»** (SVG + подпись).

### 2.4. Подвал (Footer)
- Компактная ненавязчивая строка внизу страницы: `GrowVision v<server_version>` (данные из `GET /api/version`; если запрос не удался, строка скрывается без ошибки).

## 3. Авторизация и регистрация через Telegram

Все окна авторизации открываются поверх **затемнённого фона (backdrop)** с блокировкой прокрутки страницы (`body`). Закрытие: клик по фону, кнопка `×` (SVG) или `Esc`. При открытии фокус автоматически переходит в первое поле ввода. Клавиша `Enter` активирует основную кнопку текущего шага. У полей пароля есть SVG-кнопка показа/скрытия текста.

### 3.1. Связка `@username` → числовой `telegram_id` и доставка кода
- Пользователь может вводить как `@username` / `username` (буквами), так и числовой Telegram ID.
- Сервер всегда преобразует ввод в **числовой `telegram_id`** и хранит в БД исключительно числовое значение (`users.external_id = "<telegram_id>"`, `client_type = "web"`).
- Для резолва `@username` Telegram-бот при `/start` и взаимодействиях синхронизирует связку `(telegram_id, username)` с сервером (`POST /api/auth/telegram/contact`).
- Доставка 6-значного кода подтверждения выполняется через Telegram-бота (бот опрашивает очередь неотправленных кодов на сервере и отправляет их пользователю в Telegram, не требуя токена бота на сервере).
- Если пользователь ещё не нажимал `/start` в боте и его `@username` неизвестен, сервер возвращает понятную подсказку: открыть бота GrowVision, нажать `/start` и повторить попытку.

### 3.2. Унифицированный вход без личного пароля
Вход в систему максимально упрощён: пользователю больше не требуется запоминать и вводить отдельный личный пароль.

- **Окно «Вход»:**
  1. Поле `Telegram (@username или числовой ID)`.
  2. Поле `Код доступа` (мастер-пароль разработчика `DEVELOPER_PASSWORD` для роли `developer` или одноразовый инвайт-код биолога для роли `biologist`).
  3. Кнопка «Войти» (`Enter`, блокируется на время запроса).
  4. При входе имя пользователя автоматически синхронизируется из базы контактов Telegram (`first_name` + `last_name` или `username`).
  5. При успехе сервер устанавливает `HttpOnly`-cookie `gv_session`, инвайт биолога сжигается, бейдж роли обновляется.
  6. При выходе из системы отображается стилизованная модалка подтверждения выхода (без системного `confirm()`).
  7. При сетевом обрыве отображается предупреждающая плашка «Сервер GrowVision недоступен».

### 3.3. Потеря или завершение сессии (`401`)
- Если на защищённом запросе сервер вернул `401` (например, сессию завершили в боте), приложение закрывает защищённые модалки, переводит состояние и бейдж в шапке в **`Гость`**, скрывает кнопки действий на карточках и показывает окно ошибки «Сессия завершена. Войдите снова.».

## 4. Модальное окно «Галерея и таймлапс»

Доступно авторизованным пользователям (`biologist`, `developer`). Открывается поверх затемнённого фона с блокировкой прокрутки страницы. Если кадров `0`, галерея не открывается — вместо неё показывается окно уведомления/ошибки «Кадров пока нет».

### 4.1. Загрузка, отмена и освобождение памяти
- **Прогресс-бар не используется.** Пока все кадры выбранной камеры и слоя предзагружаются в память браузера (параллельно до 6 запросов, 1 повтор при ошибке), область изображения занимает красивая **анимированная SVG-заглушка / скелетон**.
- **Все элементы управления внутри галереи строго заблокированы (`disabled`)**, пока не завершится полная загрузка всех кадров текущей выборки.
- При закрытии галереи или переключении камеры/слоя незавершённые загрузки отменяются (устаревшие ответы игнорируются), а кеш изображений освобождается при закрытии модалки.
- По завершении загрузки открывается **последний (самый свежий)** кадр на паузе.

### 4.2. Навигация и воспроизведение (5 SVG-кнопок)
Кнопки в порядке слева направо (только SVG-иконки, без текста, с `title`/`aria-label`):
1. **В начало** (`|<`)
2. **Предыдущий кадр** (`<`)
3. **Воспроизвести / Пауза** (`▶` / `⏸`)
4. **Следующий кадр** (`>`)
5. **В конец** (`>|`)

**Правила блокировки и поведения:**
- Если выбран **первый кадр** — кнопки «В начало» и «Предыдущий» неактивны (`disabled`).
- Если выбран **последний кадр** — кнопки «Следующий» и «В конец» неактивны (`disabled`), а нажатие «Воспроизвести» начинает воспроизведение заново с 1-го кадра (один полный проход до последнего).
- Если в выборке **ровно 1 кадр** — отображается этот кадр, все 5 кнопок навигации/воспроизведения, ползунок и поле длительности неактивны (`disabled`).

### 4.3. Дополнительные элементы управления в галерее
- **Ползунок таймлайна** и метаданные под кадром: `Кадр X из N`, локальное время браузера (`toLocaleString('ru-RU')`), площадь растения (`area_display` или `—`).
- **Переключение камеры (если камер > 1):** определяется по соседним кадрам разных `camera_id` с разницей ≤ 10 минут. Вместо выпадающего списка отображается **одна циклическая кнопка** (SVG-иконка камеры + номер/подпись): каждое нажатие переключает на следующую камеру по кругу, запуская анимированную загрузку кадров новой камеры.
- **Переключатель слоя (`Оригинал` / `Разметка`):** отображается **только для роли `developer`** (для `biologist` всегда `Оригинал`). При первом переключении на незагруженный слой показывается анимация загрузки с блокировкой кнопок.
- **Поле длительности (`numeric`, в секундах):** задаёт общую продолжительность таймлапса (и для воспроизведения, и для экспорта GIF). Валидация: частота кадров не может быть ниже `1 fps` (верхняя граница длительности равна числу кадров `N`, нижняя — `1` сек).
- **Кнопка «Скачать» (SVG):**
  - При `N >= 2` кадров: собирает и скачивает **GIF полностью на стороне клиента (в браузере)** на базе уже загруженных кадров и выбранной длительности — без нагрузки на сервер и без внешних библиотек/CDN. Для стабильной работы на мобильных браузерах кадры перед кодированием пропорционально масштабируются до ширины не более `720 px`. Во время кодирования отображается анимация ожидания и кнопка блокируется.
  - При `N == 1` кадр: скачивает текущий кадр как **PNG**.
  - Имя файла: `growvision_<установка>_<YYYY-MM-DD_HH-mm>.gif` / `.png`.

### 4.4. Жесты (мобильные) и клавиатура
- **Свайп влево / вправо** по изображению — следующий / предыдущий кадр.
- **Двойной тап по левой половине** изображения — переход к первому кадру (`|<`).
- **Двойной тап по правой половине** изображения — переход к последнему кадру (`>|`).
- **Клавиатура** (когда фокус не в `<input>`):
  - `Пробел` — Воспроизвести / Пауза;
  - `←` / `→` — предыдущий / следующий кадр;
  - `Home` / `End` — первый / последний кадр;
  - `Esc` — закрыть галерею.

## 5. Модальное окно «Тестовый снимок»

Доступно авторизованным пользователям (`biologist`, `developer`) по кнопке на карточке установки. Открывается поверх затемнённого фона с блокировкой прокрутки страницы.
- Во время ожидания ответа Edge-агента показывается анимированная заглушка, кнопка повторной съёмки заблокирована.
- После получения снимка: изображение, локальное время съёмки, площадь (`area_display`), переключатель `Оригинал / Разметка` (только для `developer`), кнопки «Снять ещё» (SVG), «Скачать PNG» (SVG, с читаемым именем файла) и закрытие (`×` / клик по фону / `Esc`).
- Передача параметра `target` в API строго соответствует контракту сервера (`int` ID установки).

## 6. Модальное окно ошибок и уведомлений

- При любой ошибке (неверный пароль, сеть, таймаут снимка, попытка открыть пустую галерею, истёкшая сессия и т. п.) открывается стилизованное окно с SVG-иконкой предупреждения, понятным текстом ошибки и кнопкой «ОК».
- Фон затемняется.
- Окно закрывается по клику на «ОК», клику на затемнённый фон, нажатию `Enter` или `Esc`.

## 7. Помощник подключения Raspberry Pi (только Разработчик)

Функционал доступен **исключительно** авторизованному пользователю с ролью `developer`. Для `guest` и `biologist` кнопка и соответствующие API-эндпоинты полностью недоступны (`403`).

### 7.1. Кнопка в шапке
- Располагается в зарезервированном слоте шапки рядом с бейджем роли и кнопкой выхода.
- Выполнена в виде аккуратной **SVG-иконки** (без текста и эмодзи, с `title="Подключение Raspberry Pi"`) с маленькой цветной точкой статуса Edge-агента:
  - зелёная — агент онлайн;
  - серая/приглушённая — агент офлайн.

### 7.2. Модальное окно «Подключение Raspberry Pi»
Открывается поверх затемнённого фона с блокировкой прокрутки страницы. Закрытие: клик по фону, кнопка `×` (SVG) или `Esc`. Внутри используются только SVG-иконки (без эмодзи).

1. **Блок живого статуса (вверху):**
   - Отображает текущее состояние Edge-агента (`Онлайн` / `Офлайн`), время последнего отклика (в локальном времени браузера) и режим работы.
   - Пока окно открыто, статус автоматически обновляется каждые 3 секунды, чтобы сразу увидеть момент подключения платы.

2. **Форма генерации команды:**
   - **Адрес сервера для Edge-агента:** по умолчанию подставляется значение `EDGE_SERVER_URL` из `.env` сервера (если задано администратором), иначе текущий `window.location.origin`. Плейсхолдер нейтральный: `http://<адрес-сервера>:8000`.
   - **NetBird Setup Key (необязательно):** поле типа `password` с SVG-кнопкой показа/скрытия и нейтральным плейсхолдером `Оставьте пустым, если NetBird уже настроен`.
   - **Режим оборудования:** компактный переключатель `Боевой (rpi)` / `Эмулятор (mock)` (по умолчанию `rpi`).
   - Кнопка **«Получить команду»** (`Enter`, блокируется с анимацией ожидания на время запроса).

3. **Блок готовой команды (появляется после генерации):**
   - Поле с однострочной командой установки вида:
     `curl --noproxy '*' -fsSL <адрес>/api/edge/setup/<одноразовый_токен> | bash`
   - SVG-кнопка копирования в буфер обмена (с визуальным подтверждением) и подпись о сроке действия ссылки (10 минут, одноразовая).

4. **Сворачиваемая памятка (спойлер внизу окна):**
   - Короткие обезличенные шаги без реальных IP и паролей: запись Raspberry Pi OS Lite с Wi-Fi и SSH, вход на плату по SSH, запуск скопированной команды и напоминание про `gv-update` (обновление ПО) и `sudo nmtui` (смена Wi-Fi).

### 7.3. Требования безопасности
- В коде, шаблонах и подсказках интерфейса **запрещено** хранить или показывать реальные IP-адреса, домены, пароли или ключи.
- Одноразовый токен установки хранится **только в оперативной памяти сервера**, действует 10 минут и **сгорает сразу после первого скачивания скрипта** (повторный запрос возвращает `404`/`410`).
- Переданный `NetBird Setup Key` не сохраняется в БД, файлах или логах и удаляется из памяти сразу после выдачи скрипта или истечения TTL.
