# GrowVision — Спецификация веб-плеера таймлапса (MVP)

Документ описывает публичный веб-клиент GrowVision (`clients/web/`): стек, структуру файлов, используемые эндпоинты, логику выбора установки и камеры, поведение плеера, ошибки и пустые состояния.

Опирается на `API_CONTRACT.md`, `DB_SCHEMA.md` и `REPO_AND_VERSIONING.md`. Логика камер и обработка кадров согласованы с `BOT_SPEC.md` и правилом сборки видео из `API_CONTRACT.md` (раздел 4.5).

---

## 1. Назначение и архитектурные ограничения

- **Статус документа:** защищённый архитектурный документ (меняется только с согласия пользователя, `REPO_AND_VERSIONING.md`, раздел 5.3).
- **Назначение:** публичный просмотр плановых кадров установок в виде таймлапса. Только чтение, без входа и без ролей (всегда роль Гость).
- **Стек:** чистые HTML, CSS и JavaScript. Node.js, сборщики, фреймворки (React и т. п.), внешние CDN и веб-шрифты **не используются**: страница должна работать в локальной сети без интернета. Шрифты системные.
- **Структура `clients/web/`:**
  ```text
  clients/web/
  ├── assets/         # Локальные векторные фоны и ассеты (background.svg)
  ├── js/             # Модульная архитектура ES Modules:
  │   ├── api.js      # API-клиент (сессии, CSRF-куки, строгая типизация target Number/'all')
  │   ├── app.js      # Главный модуль, инициализация, шапка, маршрутизация
  │   ├── dialogs.js  # Стилизованные диалоги и тосты (отказ от alert/confirm/prompt)
  │   ├── player.js   # Объединенная модалка «Галерея и таймлапс», 4 кнопки навигации, экспорт MP4
  │   ├── units.js    # Карточки установок, превью кадра, разархивация, тумблеры реле
  │   ├── relays.js   # Групповые операции управления светом/вспышкой и сводная карта пинов
  │   ├── cameras.js  # Сканирование, привязка/отвязка и переименование камер
  │   ├── sessions.js # Управление сессиями и одноразовыми инвайт-кодами
  │   ├── system.js   # Системные настройки, автосъемка, задержка и телеметрия RPi
  │   └── terminal.js # Интерактивный веб-терминал командной строки
  ├── index.html      # Базовая разметка SPA (без эмодзи, с SVG-иконками)
  └── style.css       # Стили (backdrop-filter blur, растительный фон, скелетоны)
  ```
- **Раздача:** страницу отдаёт сам сервер FastAPI через `StaticFiles` (`REPO_AND_VERSIONING.md`, раздел 4). Адрес один и тот же, поэтому CORS не нужен, а все пути в коде **относительные**: `/api/...` и `/media/...`.
- **Изоляция и диалоги:** веб не импортирует код `server/`, `edge_agent/`, `shared/`, не имеет `.env` и секретов. Не используются вызовы `window.alert`, `window.confirm`, `window.prompt` — все уведомления выводятся через тосты, а подтверждения и ввод — через стилизованные модалки `#modal-confirm` и `#modal-prompt`.
- **Визуальный стиль:** полный отказ от эмодзи в разметке и скриптах; все пиктограммы реализованы через векторные inline SVG. Локальный растительный фон без внешних CDN.
- **Язык интерфейса:** русский, без технического сленга.

## 2. Используемые эндпоинты

Все публичные (роль Гость, `API_CONTRACT.md`, раздел 1.1):

| Эндпоинт | Назначение |
| :--- | :--- |
| `GET /api/installations?include_archived=true\|false` | Список установок для главного экрана. |
| `GET /api/timelapse/{installation_id}/frames` | Все плановые кадры установки (без пагинации, порядок `captured_at ASC`). |
| `GET /api/version` | Версия сервера для подвала страницы. |

- Картинки берутся по `raw_url` и `annotated_url` из ответа `frames` (пути вида `/media/...`).
- Параметр `camera_id` веб не использует: все кадры загружаются одним запросом, а фильтрация по камере выполняется в браузере.
- `GET /api/installations/{id}` не нужен: список уже содержит все публичные поля.

## 3. Экран «Установки» и навигация

- Навигация: у Гостя отображается только одна вкладка («Установки»). Вкладка «Свет и реле» доступна только Разработчику и содержит **только групповые действия** (включить/выключить весь свет или вспышки, тест всех реле на 3 сек, сводная карта GPIO-пинов).
- Карточка установки:
  - Превью последнего планового кадра (`last_frame_raw_url`), либо растительный плейсхолдер при отсутствии снимков.
  - Название, культура, бейдж активности/архива, последняя площадь (`last_area_display`), число камер и кадров.
  - Для Developer: индивидуальные тумблеры управления реле конкретной установки (`Свет` и `Вспышка`).
  - Кнопка `Галерея` (открывает объединенную модалку «Галерея и таймлапс»).
  - Кнопки `Снимок` и `Редактировать` (для Biologist и Developer).
  - Для архивных установок (Developer): кнопка `Восстановить` (вызывает `POST /api/installations/{id}/unarchive` с подтверждением, выводит предупреждения о занятых пинах и напоминание привязать камеры) и кнопка `Удалить`.
- Флажок `Показать архивные`: отображается **только разработчику** (`isDev`). У Гостя и Биолога скрыт; сервер для Гостя всегда возвращает только активные установки.
- Пустой список: `Установок пока нет`.
- В подвале: `GrowVision © 2026. Автономная фитомониторинговая платформа` и версия системы.

## 4. Модальное окно «Галерея и таймлапс»

Открывается по нажатию на кнопку «Галерея» на карточке установки.

### 4.1. Выбор камеры
Если к установке привязано несколько камер, в шапке модалки отображается выпадающий список камеры (`Камера: [Камера <id> ▾]`). По умолчанию загружаются кадры выбранной камеры или всех ракурсов.

### 4.2. Плавная загрузка кадров
Во время загрузки отображается плавная анимация со спиннером и статусом: `Загрузка кадров: X из N` с прогресс-баром.

### 4.3. Управление воспроизведением

Плеер оснащен 4 кнопками шаговой навигации и кнопкой воспроизведения:

| Элемент | Поведение |
| :--- | :--- |
| `\|<` | «Первый кадр»: мгновенный переход к кадру 0. |
| `<` | «Предыдущий кадр»: шаг на 1 кадр назад. |
| `Воспроизвести / Пауза` | Запуск и пауза воспроизведения. Если открыт последний кадр и флажок «Цикл» выключен, нажатие кнопки начинает проигрывание с 1-го кадра до последнего (останавливаясь на нём). |
| `>` | «Следующий кадр»: шаг на 1 кадр вперед. |
| `>\|` | «Последний кадр»: мгновенный переход к последнему кадру. |
| Ползунок | Таймлайн кадров, счетчик `Кадр X из N`. |
| Скорость | `1x`, `2x`, `4x`. |
| `Цикл` | Зацикленное воспроизведение. |

### 4.4. Слой
Переключатель `[ Оригинал ] [ Разметка нейросети ]` (`raw_url` / `annotated_url`), позиция кадра при переключении сохраняется.

### 4.5. Метаданные текущего кадра
Под картинкой выводятся: время съемки кадра в локальном времени браузера (`toLocaleString('ru-RU')` с явной пометкой местного времени), замер площади растения (`area_display`) и номер кадра.

### 4.6. Экспорт MP4 видео (Biologist / Developer)
Внутри модалки расположена панель экспорта таймлапс-видео:
- Связанные поля: `Длительность (сек)` и `Частота кадров (FPS ≥ 1)`:
  - При вводе FPS длительность пересчитывается: `duration = frames / fps`.
  - При вводе длительности FPS пересчитывается: `fps = frames / duration` (валидация `fps >= 1`).
- Кнопка `Скачать MP4`: сервер формирует видео через ffmpeg, и файл автоматически скачивается в браузере. Вывод ошибок осуществляется через всплывающие тосты.

## 5. Ошибки и пустые состояния

| Ситуация | Поведение |
| :--- | :--- |
| Сервер недоступен или `5xx` при загрузке списка | `Не удалось загрузить список установок. Сервер недоступен.` + кнопка `Повторить`. |
| `404` на `frames` (установку удалили) | `Установка не найдена` + кнопка `← К списку`. |
| `frames` пуст | `Плановых кадров пока нет. Они появятся после первой автосъёмки.` |
| Ошибка загрузки отдельной картинки | Один повтор, затем пропуск кадра и счётчик из 4.2. |
| Сервер недоступен при `🔄 Обновить` | Сообщение об ошибке над плеером, уже загруженные кадры остаются. |

Другие коды (`401`, `403`, `409`, `422`, `429`, `503`, `504`) на публичных эндпоинтах не возникают; при неожиданном ответе показывается общее `Не удалось получить данные от сервера`.

## 6. Вне рамок MVP (план масштабирования)

- График роста площади (потребуется числовое значение площади в API, сейчас отдаётся только `area_display`);
- сравнение нескольких установок рядом;
- вход и роли в вебе (управление и скачивание видео из браузера);
- прямые ссылки на конкретную установку и кадр (`#...`);
- уменьшенные превью и ленивая подгрузка кадров для очень длинных таймлапсов;
- горячие клавиши плеера (пробел, стрелки).
