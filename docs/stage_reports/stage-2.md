# Этап 2: Edge API сервера
**Результат:** принят (PASS)
**Что появилось:**
- Приложение FastAPI (server/main.py) с автоматической инициализацией базы данных и централизованной обработкой ошибок (409 Conflict, 422 Unprocessable Content).
- Проверка аутентификации Edge-устройств по заголовку X-Edge-Key с защитой от тайминг-атак.
- Реализованы 4 эндпоинта /api/edge/*: heartbeat (телеметрия RPi), commands/claim (получение команд с таймаутом 30 с), commands/{id}/result (запись результатов и регистрация камер) и captures (дедупликация, сохранение снимков и замеров).
- Сохранение файлов изображений в файловое хранилище server/media/{installation_id}/.
- Потокобезопасный in-memory state для отслеживания связей команд и снимков.
- 46 автоматических тестов (юнит и E2E), проверяющих протокол Edge API.
**Как попробовать:** `server/.venv/bin/python -m server.main` (документация API: `http://127.0.0.1:8000/docs`)
