# Этап 7.4: Общие GPIO-пины с программной синхронизацией и переименование пользователей
**Результат:** принят (PASS)
**Что появилось:**
- Общие GPIO-пины в БД: удалены уникальные индексы uq_active_light_pin и uq_active_flash_pin, разрешено использование одного пина в нескольких установках с сохранением проверки light_gpio_pin != flash_gpio_pin внутри одной установки; безопасный DROP INDEX IF EXISTS в init_db.
- Программная синхронизация реле по пину: единое состояние пина (InMemoryState) связывает все установки с общим пином; при переключении света/вспышки статус синхронно обновляется во всех установках в ядре, API (/api/control/relays), боте и CLI.
- Предупреждения о занятом пине: при создании (unit add) и редактировании (unit edit) установки с уже используемым пином операция не блокируется, выводится предупреждение «⚠️ Пин X уже занят («Установка 1»). Реле будут общими.» (с перечислением через запятую).
- Переименование пользователей: developer может переименовать любого пользователя (PATCH /api/auth/sessions/{id}, кнопка «✏️ Переименовать» в боте, auth rename в CLI); biologist — только себя (PATCH /api/auth/me, кнопка «✏️ Изменить имя» в /profile; чужого — 403 Forbidden); строгая валидация (1..64 симв.) и экранирование.
- Обновление тестов и контрактов: дедупликация пинов в релейном тесте edge_agent, 290 автотестов (Server & E2E 130, Edge 51, Bot 59, CLI 50) без замечаний.
