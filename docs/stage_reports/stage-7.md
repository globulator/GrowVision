# Этап 7: Telegram-бот (aiogram 3)
**Результат:** принят (PASS)
**Что появилось:**
- Клиент Telegram-бота на aiogram 3 с модульной архитектурой, поддержкой 3 ролей (Гость, Biologist, Developer) и авторизацией по паролю разработчика или одноразовым кодам инвайтов для биологов.
- Управление сессиями и профилем: создание/отзыв инвайтов, список сессий с киком, переименование пользователей (developer любого, biologist себя), кликабельные профили `tg://user?id=...`.
- Общие GPIO-пины и реле: поддержка общих линий света/вспышки на несколько установок, программная синхронизация состояния по номеру пина во всех клиентах, предупреждения о занятом пине.
- Галерея плановых кадров (оригинал/разметка), экспорт MP4-таймлапса (до 50 МБ) с интерактивным выбором длительности (пресеты 5/10/30 с и ручной ввод).
- Ручная съемка snap (тумблер разметки), тумблеры реле («💡 Свет: 🟢/⚪️»), кнопка «📷 Камеры установки», CV-разметка с фиолетовой шкалой BGR (240, 32, 160) и метаданными.
- Отказоустойчивость и диагностика: авто-реконнект к Telegram API при сбоях сети, aiohttp-socks, баг-заметки на «*» с кольцевым буфером, журнал JSONL и CLI-утилита bug_log.
- 290 автоматических тестов (Edge 51, CLI 50, Bot 59, Server & E2E 130) без замечаний.
**Как попробовать:** `clients/telegram_bot/.venv/bin/python -m clients.telegram_bot.main`
