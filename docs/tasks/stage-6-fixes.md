## Критерии приёмки
1. **Строгий боевой режим (rpi) без молчаливых подмен**:
   - Если `HARDWARE_MODE=rpi`: при отсутствии библиотек `gpiozero`/`lgpio` агент завершается с понятной ошибкой (не подменяя на mock); при отсутствии OpenCV кадр не захватывается и не загружается, команда получает `status: "error"`; при отсутствии файла модели или ошибке загрузки/инференса — замеры пустые (`measurements: []`), в лог пишется `ERROR`, `annotated_image` равен исходному кадру без выдуманных площадей и рисунков; при отсутствии `cv2` `aruco_area_px = null`.
   - Если `HARDWARE_MODE` отличен от `rpi` и `mock` — ошибка конфигурации при старте с завершением процесса.
   - В heartbeat `software.model_name` содержит имя реально загруженной модели или `"none"`, `gpio_mode` — реальный режим (`"rpi"` или `"mock"`).
2. **Сканирование и выбор камер**:
   - Поиск камер через `/dev/v4l/by-id` (только файлы `*-video-index0`), `hardware_id` стабильный (из имени by-id), захват по реальному пути устройства (`os.path.realpath`).
   - Неизвестный `hardware_id` даёт ошибку (не откатывается молчаливо на `video0`).
   - Пути к `/dev/v4l/by-id` и `/sys` передаются параметрами в сканер/менеджер камер для изоляции в тестах.
3. **Прогрев и тайминги кадра**:
   - Прогрев камеры `CAMERA_WARMUP_FRAMES` (по умолчанию 5 кадров).
   - Задержка после переключения реле `RELAY_SWITCH_DELAY_MS` (по умолчанию 200 мс).
   - Переменные берутся из конфига согласно `REPO_AND_VERSIONING.md` п. 3.2.
4. **Последовательность переключения света и вспышки**:
   - Основной свет в норме включён (`light=1, flash=0`).
   - На время кадра: основной свет выключается, вспышка включается (`light=0, flash=1`), происходит съёмка, затем состояние гарантированно восстанавливается (в блоке `finally`, даже при исключениях).
   - Строка лога в `debug_log_line`: `"[GPIO] Inst#N: light=0, flash=1 -> captured K frames"`.
5. **SNAP для всех камер и установок**:
   - Команда `SNAP` снимает все привязанные камеры указанной установки (в ответе массив `captures` со всеми кадрами); для `target="all"` — все активные установки.
   - Статус `done`, если успешно снят хотя бы один кадр.
6. **Полярность реле**:
   - Параметр `RELAY_ACTIVE_HIGH` (по умолчанию `true`).
   - При старте основной свет включается, вспышка выключается с учётом заданной полярности.
7. **Индексация растений**:
   - Контуры сегментации сортируются по площади (убывание), после фильтрации шума нумеруются `plant_index` подряд с 0 (`0, 1, 2, ...`).
8. **Офлайн-очередь и надежность сети**:
   - Сброс очереди (`flush`) выполняется в отдельном потоке, не более 10 пакетов за один проход, под общим `threading.Lock` (защита от параллельных flush).
   - Запись пакета в очередь атомарна: запись во временный каталог, затем `os.replace` / `rename`.
   - `send_command_result`: до 3 попыток отправки с паузой 1 с.
   - Таймаут загрузки кадра в HTTP-клиенте: 60 с.
9. **Планировщик автосъемки**:
   - Плановая съёмка запускается строго по астрономической сетке — в начале каждого N-го часа UTC (`N = capture_interval_hours` из heartbeat: `HH % N == 0, MM == 0`), а не от момента запуска процесса.
10. **Конфигурация и игнорирование**:

    - В корневой `.gitignore` добавить `*.db-wal`, `*.db-shm`.
11. **Документация**:

    - В `clients/cli` убрать упоминание CSI из справки `camera info`.
12. **CLI**:

    - `snap take` и `light main/flash/test` при `status == "error"` выводят `result_message` в `stderr` и завершаются с кодом 1.
    - `system status` показывает `model_name` в блоке ПО RPi.
