## Цель проверки
Провести независимое тестирование и верификацию комплексных исправлений раунда 4:
1. Кнопка «📷 Камеры установки» (`inst:cameras:{inst_id}`) и служебные callback-заглушки (`frm:close`, `frm:noop`, `pag:noop`).
2. Галерея плановых кадров: парсинг `res.get("frames", [])`, ролевой доступ (гость видит только последний кадр; биолог и разработчик — вся галерея).
3. Блок `🐞 DEBUG`: вывод `debug_info.get("log_line")` («Команда:», «Лог:»).
4. Валидация GPIO `0 <= pin <= 53` в мастере и редактировании без сброса FSM.
5. Фильтрация архива: только `is_archived is True` при `show_archived=True`.
6. Ручной снимок: для биолога — только `raw`-кадр через `send_photo`; для разработчика — альбом `raw` + `annotated`.
7. `/version` без «vнеизвестно», пример логина «Андрей Бармин».
8. HTML-экранирование, `aiohttp-socks`, выход при `TelegramUnauthorizedError`.
9. Сервер: удаление архивной установки с кадрами разрешено (`DELETE /api/installations/{id}` с очисткой БД и диска `server/media/...`), неархивная с кадрами — `409 Conflict`.
10. Сканирование камер: возвращаются только реально обнаруженные камеры (отключенные помечаются оффлайн и видны в карточке установки).
11. `capture_delay_sec` (паритет Server ↔ Edge ↔ Bot ↔ CLI): настройки 0.0..30.0 с (default 1.5 с), установка, бот меню и CLI команды.
12. Edge: блокировка ручной съёмки `acquire_lock(blocking=True, timeout=10.0)`, раздельный `frame_index` с 0, ступенчатая формула `compute_plant_radius` и вращение листьев.
13. Раздел 9 `PROJECT.md`: быстрые тесты, чистый `git status`, линтер `ruff` чист.
