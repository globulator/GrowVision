- **Ветка**: `stage-8/rpi-camera-vision-and-ui`
- **Режим**: FULL
- **Связанные документы**: `docs/PROJECT.md` (раздел 9), `docs/tasks/stage-8-10-rpi-camera-vision-and-ui-builder.md`, `docs/handoff/stage-8-10-rpi-camera-vision-and-ui.md`.

## Критерии приёмки

1. **Переделка раздела «Настройки Raspberry Pi» в Web UI** (`clients/web/`):
   - Полностью убрать из Web UI переключатель режимов `эмулятор (mock)` <-> `боевой режим (rpi)`.
   - Превратить модалку/раздел в информационную панель read-only телеметрии: детальное название/модель платы, режим (`Реальная плата (RPi)` или `Эмуляция (mock)` без переключателя), онлайн/офлайн статус, версия агента/сервера, CPU/RAM/температура, диск/SD-карта, число кадров в офлайн-очереди.
   - 0 Unicode-эмодзи, 0 alerts/prompts/confirms.

2. **HSV-сегментация в боевом режиме без ONNX** (`edge_agent/vision.py`):
   - При отсутствии `.onnx`-модели в боевом режиме (`mock_mode=False`) использовать `_segment_plants_hsv` как фолбэк вместо возврата `measurements=[]`. Логировать INFO/WARNING.

3. **Автоподбор лучшего качества и умный прогрев** (`edge_agent/hardware.py`):
   - Захват в `rpi`: `cv2.CAP_V4L2`, `CAP_PROP_BUFFERSIZE = 1`, предпочтение `MJPG` и максимальное разрешение из `v4l2-ctl --list-formats-ext` с кэшированием профиля камеры и безопасным фолбэком на дефолты OpenCV при ошибках.
   - Умный прогрев: базовая пауза 0.5–1.0 с после реле, затем цикл чтения кадров до стабилизации яркости (`|mean_luma(t) - mean_luma(t-1)| < 1.5` на 2–3 кадрах подряд, таймаут 3–4 с).
   - Логирование параметров в `[SNAP]` (разрешение, кодек, прогревочные кадры, luma начальная/конечная, время).
   - До 3 повторов при ошибке открытия `/dev/video*`.
   - Проверка `offline_queue.py`: отсутствие жестких ограничений в несколько кадров.

4. **Автокалибровка и карточка камеры в Telegram-боте** (`edge_agent/`, `server/`, `clients/telegram_bot/`):
   - Определение возможностей камеры (`v4l2-ctl --all`, `--list-formats-ext`: разрешение, кодеки, автофокус).
   - Кнопка «⚙️ Автокалибровка» в карточке камеры в боте со сводкой параметров. Автоподбор при привязке.

5. **Тесты и линтер**:
   - Покрытие unit- и e2e-тестами всех компонентов.
   - Чистота `ruff check .` и `ruff format --check .`.
