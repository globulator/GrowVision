# Карточка QA: Этап 8.5 / Унификация входа без личного пароля, фиксы таймлапса и отмены бота, фиксы Web SPA и изоляция mock-режима
Режим: FULL
Ветка: stage-8/ux-and-mock-isolation

Критерии приёмки:
1. Авторизация:
   - В `server/db/models.py` и `DB_SCHEMA.md` отсутствует поле `password_hash`.
   - Вход в Web SPA происходит по коду инвайта (роль biologist) или по `DEVELOPER_PASSWORD` (роль developer), без создания личного пароля.
   - Имя пользователя подтягивается из Telegram-контактов (`telegram_contacts`).
   - При выходе из Web SPA открывается стилизованная модалка подтверждения выхода (без `confirm()`).
2. Telegram-бот:
   - Кнопка «Отмена» работает на всех шагах мастера установки и возвращает в меню установок.
   - При невалидном вводе шаг FSM не сбрасывается.
   - Таймлапс: расчет длительности строго под 30 FPS, прореживание с уведомлением.
3. Web SPA:
   - Галерея не возвращает 404 при открытии установки.
   - Тестовый снимок корректно отображает изображение и переключение слоев.
   - Медиа-заглушки выполнены в цвете `#161e29` с SVG-иконками и понятными текстами.
   - Индикатор ожидания выполнен в виде SVG-анимации цикла роста растения.
   - 0 эмодзи, 0 alert/confirm/prompt, 0 X-Client-Key, 0 CDN.
4. Edge и Mock:
   - `HARDWARE_MODE=auto` в `edge_agent`.
   - Изоляция данных в mock-режиме (`growvision_mock.db` или селективный доступ) с сохранением пользователей.
   - В `install_server.sh` настраивается `sudoers` для беcпарольного перезапуска служб через `gv-update`.
5. Тесты и линтер:
   - Все unit и e2e тесты зелёные.
   - Ruff check и format чисты.
