## Цель проверки
Провести независимое тестирование и аудит контрактов этапа 8.1:

1. **Edge-агент:**
   - Наличие `trust_env=False` в `edge_agent/client.py` (вызовы не используют системные proxy).
2. **GPIO и состояние света:**
   - Разрешено совпадение `light_gpio_pin == flash_gpio_pin` (нет 422 ошибки при совпадении), выводится предупреждение.
   - В `edge_agent` при совпадении пинов свет не гаснет во время съёмки.
   - Свет по умолчанию ВКЛ (`True`), вспышка ВЫКЛ (`False`) при создании установки и старте системы. При разных пинах во время съёмки свет ВЫКЛ, вспышка ВКЛ, затем возврат в исходное.
3. **Ограничение прав Гостя:**
   - `GET /api/installations` для роли `guest` никогда не возвращает архивные установки (даже при `include_archived=true`).
   - В Web SPA и Telegram-боте для Гостя скрыт просмотр архива.
4. **Компактный UX и визуал Web SPA:**
   - Нет отдельной вкладки «Плеер», у Гостя только вкладка «Установки».
   - Карточка установки содержит последний кадр прямо на карточке и кнопку «Галерея».
   - Модалка «Галерея и таймлапс»: плавная загрузка со статусом, просмотр, плеер, скачивание MP4, пересчёт `duration = frames / fps` и `fps = frames / duration`, валидация `fps >= 1`.
   - Локальный растительный фон (SVG/CSS в `clients/web/assets/` с `blur`), плавные спиннеры/скелетоны, inline SVG-иконки вместо эмодзи.
5. **Объединение галереи и таймлапса в Telegram-боте:**
   - Отдельный раздел меню «Таймлапс» убран.
   - Внутри Галереи кнопка «Сформировать таймлапс» (или «Скачать таймлапс») запускает диалог: ввод длительности -> ввод/настройка FPS (`fps >= 1`) -> экран сводки («Подтвердить» / «Отмена») -> отправка MP4.
6. **Правила скорости и тестов (Раздел 9 PROJECT.md & qa_tester.md):**
   - Быстрые тесты (<3 с на тест, весь набор <60 с, без `sleep`).
   - Fail-fast и аудит контрактов.
   - Чистый `git status --short`, линтер `ruff check .` и `ruff format --check .` чистые.
