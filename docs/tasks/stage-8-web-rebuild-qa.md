# Карточка QA: Этап 8.3 — Приёмка пересобранного Web SPA

**Ветка**: `stage-8/web-rebuild`  
**Исполнитель**: QA-инженер  
**Контрольные требования**:

1. **Регистрация и вход через Telegram**:
   - Синхронизация контактов через `POST /api/auth/telegram/contact`.
   - Опрос и доставка кодов через `GET /api/auth/web/pending-codes` и `POST /api/auth/web/pending-codes/{id}/ack`.
   - Полный цикл регистрации: `/register/start` -> `/register/verify` -> `/register/complete` (сохранение числового `external_id=str(telegram_id)`, сжигание инвайта биолога, cookie `gv_session`).
   - Вход по логину/паролю `/login`, статус текущего пользователя `/me`, выход `/logout`.
2. **Шапка, панель раздела, карточки, подвал**:
   - Бейдж роли (`Гость` / `Биолог` / `Разработчик`) всегда виден в шапке.
   - Заголовок «Установки» и кнопка обновления с анимацией.
   - `GET /api/installations` отдаёт `frames_count` и `last_frame_url`.
   - Для Гостя: превью (или заглушка), название, культура; кнопок действий нет.
   - Для авторизованных: кнопки «Галерея» (disabled при 0 кадров) и «Тестовый снимок».
   - Подвал с версией из `GET /api/version`.
3. **Модалка «Галерея и таймлапс»**:
   - Анимированная заглушка предзагрузки БЕЗ прогресс-бара; блокировка кнопок до завершения загрузки; отмена незавершенных запросов при закрытии.
   - При 0 кадров: модалка «Кадров пока нет».
   - 5 SVG-кнопок: `|<`, `<`, `▶/⏸`, `>`, `>|`. Блокировка границ, рестарт воспроизведения при Play на последнем кадре.
   - При 1 кадре: навигация disabled, скачивание PNG.
   - Клиентский экспорт GIF на Canvas (до 720 px, 0 сетевых запросов).
   - Циклическая кнопка камер; тумблер слоя для dev; поле длительности; жесты и клавиши.
4. **Тестовый снимок**:
   - Передача `target` строго как `int` (число).
   - Показ изображения, даты/времени, площади; тумблер слоя для dev; кнопки «Снять ещё» и «Скачать PNG».
5. **Чистота Web SPA**:
   - 0 Unicode-эмодзи в `clients/web/` (только SVG).
   - 0 вызовов `window.alert`, `window.confirm`, `window.prompt`.
   - 0 внешних CDN / скриптов / шрифтов.
   - 0 заголовков `X-Client-Key` в `clients/web/`.
6. **Тесты и качество**:
   - Все unit- и e2e-тесты зелёные.
   - `ruff check .` и `ruff format --check .` чисты.
   - Рабочая директория чиста.
