## Правила скорости и тестов (Раздел 9 PROJECT.md):
1. Тесты быстрые: один тест не дольше 3 с (тест с настоящим ffmpeg до 10 с), весь набор не дольше 60 с. Настоящие ожидания (sleep, ответ RPi 10/15 с, пороги 30/60/90 с) в тестах запрещены: константы времени подменяются через monkeypatch.
2. Состояние для тестов готовится через публичные эндпоинты (RPi онлайн только через POST /api/edge/heartbeat). Прямая запись в БД допустима только для данных, у которых нет эндпоинта.
3. QA и Builder выносят общие фикстуры в conftest.py и используют их повторно.
4. Любой запуск тестов выполняется как `timeout 300 ... pytest`, у вызовов ffmpeg стоит timeout.
5. Две подряд неудачные попытки починить один и тот же тест: стоп, вернуть статус BLOCKED с описанием причины, не делать третью попытку наугад.
6. Чистый git status: после прогона тестов и работы не должно оставаться временных файлов (например `growvision.db*`, файлов в `server/media/` кроме `.gitkeep`). Линтер и форматтер `ruff` должны проходить без ошибок.

## Критерии приёмки:

1. **Поддержка веб-авторизации на сервере (`server/api/auth.py`, `server/api/deps.py`, `server/main.py`):**
   - Поддержать `client_type = "web"` с `HttpOnly`-cookie (`SameSite=Lax`) без передачи `X-Client-Key` из браузерного JS:
     - Эндпоинты `/api/auth/web/login`, `/api/auth/web/logout`, `/api/auth/web/me` (или прозрачная поддержка куки в `deps.py` для всех `/api/*` эндпоинтов).
     - При входе: пароль разработчика -> роль `developer`, одноразовый инвайт-код -> роль `biologist`.
     - При первом входе без логина: возвращать `{"status": "needs_login", "role": role}` без сжигания инвайт-кода для запроса имени и фамилии.
     - При повторном входе: автоматическое подтягивание имени из существующего профиля.
     - Веб-сессии корректно отображаются, переименовываются и принудительно завершаются (кикаются) через `GET /api/auth/sessions` и соответствующие эндпоинты сессий.
   - Раздача статики `clients/web/` через FastAPI `StaticFiles` на `/` (без конфликтов и перекрытия `/api/*` и `/media/*`).

2. **Полноценный Web SPA (`clients/web/` — чистые HTML/CSS/JS, без Node.js, сборщиков, фреймворков и CDN):**
   - **Архитектура и стиль:**
     - Структура: `clients/web/index.html`, `clients/web/style.css`, модули в `clients/web/js/` (например, `api.js`, `app.js`, `player.js`, `terminal.js`).
     - Адаптивная вёрстка (телефон от 360 px и ПК), современный лаконичный UI, системные шрифты, русский язык.
     - Защита от XSS: использование `textContent` / строгое экранирование при вставке в DOM.
   - **Ролевая модель:**
     - **Гость (без входа):** просмотр списка активных/архивных установок и плеер таймлапса. Кнопка «Войти».
     - **Биолог:** просмотр и редактирование (название, культура) установок, ручной снимок (`raw`), тумблеры света и вспышки, плеер таймлапса (`raw`), скачивание MP4, смена своего имени в профиле, кнопка «Выйти».
     - **Разработчик:** полный доступ ко всем функциям:
       - **Установки:** список, карточка, создание/редактирование с валидацией GPIO (0..53) и предупреждением о занятых пинах (`⚠️ Пин X уже занят («...»). Реле будут общими.`), архивация, удаление с подтверждением, ручной снимок с тумблером «Оригинал / Разметка».
       - **Плеер таймлапса и видео (по `docs/WEB_SPEC.md`):**
         - Автоопределение камер по пороговому интервалу 10 мин.
         - Предзагрузка до 6 параллельных запросов с полосой прогресса и блокировкой управления.
         - Воспроизведение: Play/Pause, ползунок кадра, шаг вперед/назад, скорости 1x (5 fps) / 2x / 4x, зацикливание.
         - Переключатель слоя: `🖼 Оригинал` / `🧠 Разметка` (с сохранением текущего кадра).
         - Метаданные: дата/время в локальном времени браузера, `area_display`, номер кадра.
         - Сборка и скачивание MP4-видео с выбором камеры и длительности (рекомендованное + пресеты/ввод).
       - **Камеры:** список, сканирование подключенных камер (с выводом debug-лога), привязка/отвязка, редактирование названия.
       - **Свет и реле:** тумблеры состояния света и вспышки с синхронизацией по пину + кнопка «Тест реле».
       - **Сессии:** генерация одноразовых инвайт-кодов (в `<code>` с копированием, TTL 10 мин), список активных кодов с отзывом, список всех сессий (активные/неактивные), карточка сессии с кнопками переименования и кика.
       - **Система:** статус Edge-агента (онлайн/оффлайн, время последнего heartbeat, телеметрия), версия сервера, переключатели `debug_mode` и `auto_capture`.
       - **💻 Терминал GrowVision:** интерактивная веб-консоль команд GrowVision (`help`, `status`, `unit`, `cam`, `light`, `flash`, `snap`, `relay-test`, `auth`, `sys`, `clear`) с историей ввода (`↑/↓`), выводом ответа и блока `debug_log_line`.

3. **Документация и тесты:**
   - Обновить `docs/API_CONTRACT.md` (описание эндпоинтов веб-авторизации) и `docs/USER_GUIDE.md` (раздел Web SPA).

     - Отсутствие утечек `X-Client-Key` в JS-файлах `clients/web/`.
   - Соблюдать правила Раздела 9 PROJECT.md: быстрые тесты (<3 с на тест), чистый git status, линтер `ruff` чист.
