# Карточка задачи: QA-проверка Этапа 8 (Полноценный Web SPA-клиент)

- **Компонент**: `server`, `clients/web`, `tests/e2e`
- **Ветка**: `stage-8/web-spa`

- **Спецификации**: `docs/PROJECT.md` (включая раздел 9), `docs/WEB_SPEC.md`, `docs/API_CONTRACT.md`, `docs/USER_GUIDE.md`
- **Отчёт реализации**: `docs/handoff/stage-8-web.md`

## Цель проверки
Провести независимое тестирование и аудит контрактов Web SPA-клиента:

1. **Сервер и веб-авторизация (`server/`):**
   - Раздача статики `clients/web/` на `/` через `StaticFiles` (не затрагивая `/api/*` и `/media/*`).
   - Веб-авторизация через `HttpOnly`-cookie (`SameSite=Lax`, `client_type="web"`):
     - Вход по паролю разработчика -> `developer`.
     - Вход по активному коду инвайта -> `biologist`.
     - Первый вход без имени -> статус `needs_login` без сжигания кода, последующий вход с именем активирует сессию и сжигает код.
     - Повторный вход -> имя подтягивается из профиля.
     - Корректная работа защищенных эндпоинтов `/api/*` через cookie-авторизацию.
     - Принудительное завершение веб-сессии (кик) деактивирует доступ (`is_active=False`).
     - Переименование сессии обновляет имя пользователя.
   - Отсутствие утечек `X-Client-Key` в JS-файлах `clients/web/` (проверка `grep -rn "X-Client-Key" clients/web/` должна быть пустой).

2. **Web SPA-клиент (`clients/web/`):**
   - Нативные HTML, CSS и JS без сборщиков, Node.js, сторонних фреймворков и внешних CDN.
   - Адаптивность от 360 px, аккуратный русский UI, экранирование XSS (`textContent`).
   - Ролевая модель: Гость, Биолог, Разработчик с разграничением видимости и действий.
   - Установки: создание/редактирование с предупреждением об общих пинах, архивация, удаление, ручной снимок (для dev с тумблером разметки).
   - Плеер таймлапса по `docs/WEB_SPEC.md`: выбор камер по порогу 10 мин, предзагрузка до 6 параллельно с прогрессом, Play/Pause, ползунок, шаги, скорости 1x/2x/4x, зацикливание, переключатель слоя, локальное время, экспорт MP4.
   - Камеры, реле (синхронизация тумблеров по пину, тест реле), сессии (инвайты, кик, переименование), система (статус, debug_mode, auto_capture).
   - 💻 Терминал разработчика: интерактивная консоль GrowVision (`help`, `status`, `unit`, `cam`, `light`, `flash`, `snap`, `relay-test`, `auth`, `sys`, `clear`, история `↑/↓`).

3. **Правила скорости и тестов (Раздел 9 PROJECT.md & qa_tester.md):**
   - Быстрые тесты (<3 с на тест, весь набор <60 с, без `sleep`).
   - Fail-fast и аудит контрактов.
   - Чистый `git status --short`, линтер `ruff check .` и `ruff format --check .` чистые.
